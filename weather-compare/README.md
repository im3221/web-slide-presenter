# 🌏 세계 날씨 비교 예보

세계 주요 기상기관의 예보 모델을 한 화면에서 비교하고, 모델 합의로 종합 예측을 계산하는 웹앱입니다.
설치 없이 `index.html`을 브라우저로 열면 바로 동작합니다(인터넷 연결 필요, API 키 불필요).

## 비교하는 예보 모델
| 모델 | 기관 |
|---|---|
| KMA | 대한민국 기상청 |
| ECMWF IFS | 유럽중기예보센터 |
| GFS | 미국 해양대기청(NOAA) |
| ICON | 독일 기상청(DWD) |
| JMA | 일본 기상청 |
| UKMO | 영국 기상청 |
| ARPEGE/AROME | 프랑스 기상청 |
| GEM | 캐나다 기상청 |

네이버·AccuWeather·Weather.com 등 날씨 사이트와 앱은 대부분 이 원천 모델을 가져와 자체 보정합니다.
상업 서비스는 유료 API 키가 필요해 수치를 직접 가져오지 않고, 같은 지역 예보를 여는 링크를 제공합니다.

## 기능
- 도시 검색(한글/영문), 현재 위치, 주요 도시 바로가기 (마지막 지역 기억)
- 종합 예측: 현재 기온, 오늘·내일 최고/최저, 강수 확률, 신뢰도, 요약 문장, 생활 조언(우산·옷차림·폭염·한파·강풍)
- 7일 종합 예보 + 날짜별 신뢰도
- 모델별 예보 비교표 (종합보다 2.5° 이상 차이 나면 색 강조)
- 시간별 기온(48시간/7일), 일별 강수량, 최고기온 예측 범위 차트
- 예보 분석: 비 오는 날, 가장 확실한/불확실한 날, 튀는 모델, 강수량 많고 적은 모델
- 비교할 모델 켜고 끄기, 라이트/다크 테마, 모바일 화면 지원
- 네트워크 오류 시 예시 데이터로 화면 표시

## 예측 방법
- **종합 기온**: 모델 5개 이상이면 최댓값·최솟값을 뺀 평균(절사평균)
- **강수 확률**: 하루 1mm 이상 비를 예측한 모델의 비율
- **신뢰도**: 모델 간 최고기온 차이와 강수 의견 일치도로 0~100점 계산
